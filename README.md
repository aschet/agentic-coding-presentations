# Agentic Coding Presentations

## `local_agentic_coding.tex`

Local, Open-Weight Agentic Coding is a Beamer slide deck on running
agentic coding models locally: hardware requirements, tooling (inference
servers and coding harnesses), model selection, and the state of public
benchmarks. Includes an appendix with setup instructions for common tools.

Compile with:

```
lualatex local_agentic_coding.tex
```
